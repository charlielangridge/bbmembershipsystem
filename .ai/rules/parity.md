# Parity

## Preserve complete legacy feature parity
Every capability classified in docs/parity/features.md is required before the parity programme closes. The exact P0/P1/P2 assignments remain proposed until product-owner approval. Start the confirmed final tranche—direct-debit migration, PayPal, CCTV, Discord, API documentation, and secure log viewing—only after every other required capability is accepted. Preserve outcomes and external contracts with supported replacements; obsolete packages and unsafe protocols are not parity requirements.
