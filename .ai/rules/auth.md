# Auth

## Use Fortify for authentication
Fortify is the authoritative authentication backend. Retain registration, password reset, email verification, password confirmation, two-factor authentication, and passkeys. Build UI through the Inertia Vue starter-kit flows and Fortify routes; do not port the legacy Laravel 5 auth implementation.
